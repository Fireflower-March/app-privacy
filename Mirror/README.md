# Mirror 隐私政策与技术支持

Mirror 仅显示 **1080p、每秒 60 帧**的相机实时画面，仅需相机权限，不进行图像分析、识别或额外图像处理，不录制、保存、上传或收集相机画面。

## 维护与部署

纯静态 HTML 和 CSS，无 JavaScript、依赖或构建步骤。目录独立包含 `styles.css`，支持移动端、深色模式和打印。保留仓库现有 GitHub Pages 发布方式，将本目录随 `main` 分支发布。

文案依据当前“仅相机预览”的功能范围编写，开发者与联系方式沿用本仓库。此仓库不包含 Mirror App 源码。实际版本的功能、权限和 SDK 应与政策保持一致；新增录制、保存、图像分析、联网或数据收集行为时，同步更新五种语言的政策与日期。

相机权限与系统设置的官方参考：[Apple 相机权限说明](https://support.apple.com/guide/iphone/control-access-to-hardware-features-iph168c4bbd5/ios)、[NSCameraUsageDescription](https://developer.apple.com/documentation/bundleresources/information-property-list/nscamerausagedescription)。网页托管信息的官方参考：[GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。
